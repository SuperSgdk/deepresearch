# DeepResearch 项目说明

DeepResearch 是由 SuperSgdk 设计与开发的个人多智能体研究项目。项目将问题拆解、多来源检索、证据审查和报告生成串成完整流程，通过意图识别选择快速问答或研究路径。

研究流程由 LangGraph 编排：规划研究问题，执行博查网络搜索和 Milvus 本地知识库检索，等待双源完成后审查证据，分析结论与信息缺口。资料不足时生成补搜计划，达到上限后撰写 Markdown 报告。

FastAPI 提供研究与健康接口，Vue 3 网页通过 SSE 展示节点完成事件及最终报告。PostgreSQL 保存对话记忆与工作流检查点，Milvus 存放知识片段及语义记忆，两个集合分别为 mult_agent_knowledge 与 mult_agent_memory。

新建聊天生成新的会话 ID。后台检查点按租户、用户、会话组合划分；长期记忆默认按用户保存，因此同一用户新建聊天仍可能召回偏好或历史信息。

本项目没有登录鉴权、限流、任务队列或正式生产部署验收。来源编号存在不代表来源支持全部结论。该文件记录个人项目的功能与边界，同时用于入库验证，不是市场研究数据或性能测试报告。
